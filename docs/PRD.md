# 产品需求文档 (PRD) - 拾遗 eleven

## 产品概述
Windows 桌面剪贴板管理工具，支持多内容暂存、混合类型存储、全局快捷键浮窗面板。

## 核心功能 (P0 - MVP)

### F1 剪贴板监听引擎
- 后台监听系统剪贴板变化 (Win32 AddClipboardFormatListener)
- 区分内容类型：纯文本 / RTF / 图片 / 文件列表
- 去重：连续相同内容不重复存储
- 容量上限：默认保留最近 100 条

### F2 暂存面板 UI
- 全局快捷键 Ctrl+Shift+H 唤出/隐藏
- 浮窗形式，置顶，点击外部关闭
- 列表展示：缩略图/文本预览 + 时间 + 类型图标
- 点击条目 → 写入系统剪贴板 → 自动隐藏 → 用户 Ctrl+V 粘贴
- 支持删除单条、清空全部

### F3 内容类型支持
| 类型 | 存储 | 预览 |
|------|------|------|
| 纯文本 | 原文，截断 10KB | 前 2 行 |
| RTF/HTML | HTML 源码 | 渲染或降级纯文本 |
| 图片 | PNG 本地文件 | 缩略图 80x80 |
| 文件 | 路径列表 | 文件名 + 图标 |

## 增强功能 (P1)
- F4 拖拽出：从面板拖到目标 App (DoDragDrop API)
- F5 置顶/收藏：钉住常用内容
- F6 内容合并：多条合并为一条

## 进阶功能 (P2)
- F7 全文搜索 (SQLite FTS5)
- F8 系统托盘 + 开机自启
- F9 数据导入导出

## 远期功能 (P3)
- F10 跨设备同步 (局域网 P2P 或中转服务器)

## 非功能需求
| 项目 | 要求 |
|------|------|
| 启动 | < 2s |
| 内存 | < 80MB |
| 响应 | 快捷键唤出 < 200ms |
| 隐私 | 本地存储，不联网 |
| 兼容 | Win10/11, 高 DPI |
